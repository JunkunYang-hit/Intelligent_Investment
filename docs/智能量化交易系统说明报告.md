# 智能量化交易系统说明报告

**项目名称：** Intelligent Investment Demo<br>
**系统类型：** 面向大盘标的的低频量化交易教学系统<br>
**报告日期：** 2026 年 9 月 20 日

---

## 1. 系统概述

本系统是一套面向课程展示和团队协作开发的智能量化交易 Demo。系统围绕“行情数据—策略信号—订单风控—成交撮合—账户记账—绩效分析—结果展示”建立完整链路，同时提供模拟券商、联网行情、回测历史和 DeepSeek AI 分析功能。

系统采用 Python 开发，核心交易逻辑与 Web 展示分离。用户可以通过蓝白色中文界面完成标的选择、策略配置、历史回测、结果分析、模拟下单和 AI 提问。

## 2. 核心功能

| 功能模块 | 功能说明 |
|---|---|
| 行情数据 | 读取本地前复权日 K 数据，并按需获取腾讯公开行情快照 |
| 标的选择 | 提供 13 个大盘指数、行业和跨市场代表性 A 股标的 |
| 策略研究 | 支持双均线、RSI、MACD 和布林带四种低频策略 |
| 历史回测 | 一次性快速完成指定区间回测，并生成净值曲线和交易记录 |
| 交易执行 | 支持订单生成、风控校验、下一交易日开盘成交和交易费用 |
| 账户管理 | 维护现金、持仓、平均成本、已实现盈亏和浮动盈亏 |
| 绩效分析 | 计算收益率、年化收益率、最大回撤、Sharpe、胜率和费用 |
| 回测历史 | 自动保存完整报告，可恢复结果并分页查看成交和订单 |
| 模拟券商 | 支持本地 PaperBroker 和富途 OpenD 官方模拟盘 |
| AI 分析 | 使用 DeepSeek 结合行情统计，从趋势、风险等角度分析标的 |
| Web 界面 | 提供总览、回测、券商、AI、历史和交易记录页面 |

## 3. 总体架构

系统按职责拆分为多个相互独立的模块：

```text
用户操作
   ↓
Web 页面与 HTTP API
   ↓
数据服务 → 策略模块 → 仓位计算与风控 → 订单管理
                                      ↓
                              回测撮合 / 券商网关
                                      ↓
                              账户、持仓与绩效
                                      ↓
                          页面展示与回测历史保存
```

主要目录如下：

```text
config/                         系统配置
examples/                       示例行情数据和股票池说明
src/quant_demo/
├── data/                       数据读取、清洗、选股和联网行情
├── strategy/                   策略与技术指标
├── modes/                      回测流程与运行模式
├── trading/                    仓位、风控、订单、撮合和账户
├── analytics/                  绩效计算
├── brokerage/                  本地、富途和 QMT 券商适配器
└── web/                        Web 服务、AI 和历史记录
tests/                          自动化测试
docs/                           项目说明文档
```

模块之间通过统一的数据对象和公开接口协作，网页只负责收集参数与展示结果，不重复实现交易逻辑。

## 5. 策略模块

系统提供四种规则清晰、便于解释的低频策略。

### 5.1 双均线策略

计算短期和长期移动平均线。短均线上穿长均线时产生买入信号，下穿时产生卖出信号，适合观察中期趋势。

主要参数：短均线周期、长均线周期和目标仓位。

### 5.2 RSI 策略

使用相对强弱指标判断价格状态。RSI 进入超卖区域时买入，进入超买区域时卖出，适合震荡行情研究。

主要参数：RSI 周期、超卖阈值和超买阈值。

### 5.3 MACD 策略

根据快线、慢线及信号线的交叉生成交易信号，属于趋势跟随策略。

主要参数：快线周期、慢线周期和信号线周期。

### 5.4 布林带策略

利用移动平均线和标准差形成上下轨。价格跌破下轨时买入，升破上轨时卖出，用于研究价格的均值回归特征。

主要参数：计算周期和标准差倍数。

所有策略只能读取当前及以前的数据，避免在回测中使用未来信息。

## 6. 回测与交易规则

回测引擎按时间顺序处理日 K 数据，完整流程如下：

1. 读取当前交易日行情；
2. 策略根据当前及历史数据生成信号；
3. 仓位模块计算目标交易数量；
4. 风控模块检查资金、仓位和订单限制；
5. 订单进入订单管理系统；
6. 信号在当日收盘后产生，订单在下一交易日开盘成交；
7. 成交结果更新现金、持仓和盈亏；
8. 每个交易日记录账户净值；
9. 回测结束后计算绩效指标并保存报告。

系统支持 A 股整手交易规则，并为科创板标的配置对应交易单位。目标仓位可在 1% 至 100% 之间设置。

交易成本包括：

- 买卖佣金；
- 最低佣金；
- 卖出印花税；
- 固定滑点。

所有成本参数都集中保存在 `config/demo.json`，便于团队统一口径。

## 7. 账户、持仓与风控

账户模块以成交结果作为资金和持仓变化的唯一入口，避免策略直接修改账户数据。

账户记录内容包括：

- 可用现金；
- 持仓数量；
- 平均持仓成本；
- 最新价格；
- 持仓市值；
- 已实现盈亏；
- 浮动盈亏；
- 总资产；
- 累计交易费用。

仓位模块根据目标仓位、账户资产、当前持仓、证券价格和交易手数计算订单数量。风控模块负责检查订单金额、单标的仓位和可用资金，并对不符合要求的订单给出明确原因。

## 8. 绩效指标

回测结束后，系统生成一组容易解释的核心指标：

| 指标 | 说明 |
|---|---|
| 总收益率 | 回测期末资产相对初始资金的变化比例 |
| 年化收益率 | 将回测收益按一年 252 个交易日折算 |
| 最大回撤 | 净值从历史高点到后续低点的最大跌幅 |
| Sharpe 比率 | 单位波动对应的收益水平 |
| 胜率 | 已完成交易周期中盈利交易的比例 |
| 交易次数 | 实际成交记录数量 |
| 总费用 | 佣金、印花税和滑点等成本总和 |
| 最终资产 | 回测结束时现金与持仓市值之和 |

页面同时绘制策略净值与买入持有基准曲线，帮助用户比较策略表现与标的自身涨跌。

## 9. 模拟券商

### 9.1 本地 PaperBroker

本地模拟券商不需要账户和额外软件，可以维护模拟资金、持仓和订单，用于课程演示和交易链路验证。

本地下单使用联网行情作为价格参考，并执行 A 股交易时段保护：

- 上午：09:30—11:30；
- 下午：13:00—15:00；
- 周末、休市时间或行情日期不符合要求时拒绝订单。

### 9.2 富途官方模拟盘

系统可以从网页选择富途 OpenD 官方模拟盘，填写主机、端口、港股或美股市场以及可选模拟账户 ID。连接成功后，资金、持仓和订单由富途模拟账户提供。

网页固定使用富途 `SIMULATE` 环境。连接参数只保存在当前服务进程内存中，不保存账户密码。

### 9.3 统一券商接口

本地模拟与富途模拟盘实现相同的券商接口，包括：

- 建立与断开连接；
- 提交市价单或限价单；
- 查询订单；
- 查询持仓；
- 查询可用资金；
- 撤销订单。

统一接口使交易逻辑不依赖具体券商实现。

## 10. AI 标的分析

AI 页面支持选择标的、输入 DeepSeek API Key 和自然语言问题。后端会自动加入隐藏的分析要求，并向模型提供系统计算的行情信息，包括：

- 最新价格与行情时间；
- 5 日、20 日和 60 日收益；
- 20 日和 60 日移动平均；
- 60 日年化波动率；
- 120 日最大回撤；
- 最新成交量相对 20 日均量的比例。

隐藏提示词要求模型从趋势、动量、波动、回撤、成交量、策略适配性和风险等角度分析，同时明确数据限制，避免虚构新闻、公告或财务信息。

DeepSeek API Key 只随当次请求发送，不写入配置、浏览器存储或回测历史。

## 11. Web 页面

Web 系统采用蓝白色主题，包含以下页面：

### 11.1 系统总览

展示数据范围、标的数量、数据检查结果、核心绩效和系统交易链路。

### 11.2 策略回测

提供标的、日期、策略参数、初始资金和目标仓位输入。点击“一键快速回测”后直接完成整个历史区间计算。

### 11.3 模拟券商

### 11.4 AI 分析

展示行情背景，接收用户问题并显示 DeepSeek 分析结果。

### 11.5 回测历史

列出已保存报告，可恢复当次指标和净值曲线，也可分页查看成交与订单。

### 11.6 交易记录

显示当前券商连接会话中的订单，支持查看全部订单或只查看已成交订单。

## 12. 回测历史与数据保存

每次成功回测后，系统自动将完整结果保存到 `.quant_demo/backtests/`。保存内容包括：

- 运行时间与请求参数；
- 标的、策略和回测区间；
- 绩效指标；
- 每日净值曲线；
- 买入持有基准曲线；
- 全部订单；
- 全部成交；
- 数据快照编号和运行信息。

历史页面可以读取、展示和删除报告。交易明细采用每页 10 条的分页方式，避免大量记录影响页面阅读。

## 13. 配置管理

`config/demo.json` 集中保存系统运行参数：

```text
market     数据频率、股票池、中文名称和交易手数
backtest   初始资金、佣金、印花税、滑点和年交易日数
strategy   默认策略、策略参数和目标仓位
risk       订单金额和单标的仓位限制
```

集中配置可以减少成员之间的参数差异，并方便课堂展示时调整初始资金和交易规则。

## 14. 安装与复现

### 14.1 环境要求

- Python 3.9 或更高版本；
- Git；
- Chrome、Edge 或其他现代浏览器；
- 可访问腾讯行情和 DeepSeek 的网络环境。

### 14.2 获取项目

```powershell
git clone https://github.com/JunkunYang-hit/Intelligent_Investment.git
cd Intelligent_Investment
```

### 14.3 创建虚拟环境

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

使用 Conda 时可以执行：

```powershell
conda create -n quant-demo python=3.11 -y
conda activate quant-demo
pip install -e ".[dev]"
```

### 14.4 安装富途支持

```powershell
pip install -e ".[dev,futu]"
```

富途模拟盘还需要在本机启动并登录 OpenD，默认连接地址为 `127.0.0.1:11111`。

### 14.5 运行测试

```powershell
python -m pytest -q
```

### 14.6 启动系统

```powershell
quant-web
```

浏览器访问：

```text
http://127.0.0.1:8000
```

也可以指定端口、数据、配置和历史目录：

```powershell
quant-web --port 8080
quant-web --data examples/stocks_5y.csv --config config/demo.json
quant-web --history-dir .quant_demo/my-backtests
```

## 15. 使用流程

推荐按照以下顺序演示系统：

1. 在系统总览查看数据范围和系统结构；
2. 进入策略回测，选择标的和策略；
3. 设置日期、初始资金、目标仓位和策略参数；
4. 运行快速回测；
5. 查看收益、最大回撤、Sharpe、胜率和净值曲线；
6. 在回测历史中查看保存结果、成交和订单；
7. 在模拟券商中选择交易通道并查看账户；
8. 在有效交易时间提交模拟订单；
9. 在交易记录中检查订单状态；
10. 在 AI 分析页面结合行情数据提出问题。
