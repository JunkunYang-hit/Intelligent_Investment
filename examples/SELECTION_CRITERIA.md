# 选股标准（Stock Selection Criteria）

本文件定义股票池的**清晰、可计算、可复现**的选股标准（响应课程修改意见），
标准实现在 `src/quant_demo/data/selection.py`，下表数字由该模块对
股票池真实数据实时计算生成，任何人运行 `screen_universe()` 都可复现。

## 一、准入筛选（S1~S4，量化可计算，代码强制执行）

| 规则 | 标准 | 校准依据 |
|------|------|----------|
| S1 数据完整性 | 近5年交易日 ≥ 1190 天 | 5年约1209个交易日，容忍少量停牌 |
| S2 流动性 | 日均成交额 ≥ 2亿（市场本币） | 大盘股门槛；池内最低长江电力17.7亿 |
| S3 数据质量 | 无单日涨跌幅跳变：A股 >25%、港美 >45% | A股涨跌停±10%/±20%不可能超25%；
| | | 港美阈值45%容纳真实极端行情（2022-03-16中概股行情 BABA +36.8%），
| | | 拆股假跳变(-67%~-95%)必被拦截 |
| S4 价格有效性 | OHLC 合法且为正 | `Bar.__post_init__` 构造时强制校验 |

## 二、定性标准（Q1~Q3，依据公开市场数据人工核对）

| 规则 | 标准 | 说明 |
|------|------|------|
| Q1 板块代表性 | 每个目标板块选市值最大的龙头 | 覆盖8大板块（消费/金融/新能源/医药/半导体/公用/能源/资源） |
| Q2 高分红属性 | 近三年平均股息率 ≥ 3% | 计入「高分红」标签，共5只（招行/平安/长电/中石油/格力） |
| Q3 对照价值 | 重点板块保留两只龙头 | 如贵州茅台/五粮液同板块横向对照 |

## 五、动态选股：动量排名（供策略层调用）

准入筛选决定「池子里有哪些票」，动量排名决定「每个调仓日买哪些」：

```python
from datetime import datetime
from quant_demo.data import momentum_rank

# 调仓日按过去60个交易日收益率降序取前5
top5 = momentum_rank(bars, as_of=datetime(2026, 9, 1), lookback=60, top_k=5)
```

规则：得分 = 当日收盘 ÷ 60日前收盘 − 1；数据不足60日的标的不参与排名。

## 七、数据源已知限制（诚实披露）

1. **美股拆股不做复权**：该接口对 NVDA(2024-06 1拆10)、GOOG(2022-07 1拆20)、
   TSLA(2022-08 1拆3) 不做前复权，呈现为单日 -90%/-95%/-67% 假跳变（实测确认），
   **因此美股池剔除窗口内有拆股的标的**，仅收录 AAPL/MSFT/BABA/JPM/KO/XOM
   （2021-09~2026-09 均无拆股）；拉取脚本内置跳变检查，命中即拒绝写入。
2. **港股日期为当地交易日历**，美股日期为美东交易日；跨市场对齐由使用方处理。
3. 510300.SH 为 ETF：BaoStock 无 ETF 行情时映射沪深300指数（走势一致，README 约定）。
