## 数据说明

- **数据来源**：腾讯行情接口，`scripts/fetch_global_data.py` 自动拉取（按年分段+拼接去重）。
- **复权方式**：前复权（qfq）。
- **交易日历**：港股为港交所日历（约246天/年），美股为美东日历（约250天/年）；
  跨市场日期对齐由使用方按各自日历处理。
- **成交量单位**：港股/美股均为股；币种分别为 HKD / USD（成交额换算见 SELECTION_CRITERIA.md）。
- **拆股限制（重要）**：数据源对美股拆股不做复权（实测 NVDA/GOOG/TSLA 呈现
  单日 -90%/-95%/-67% 假跳变），因此美股池**只收录窗口内无拆股的标的**；
  拉取脚本内置「单日跳变 >45% 拒绝写入」的质量门禁。
- **更新方法**：`python scripts/fetch_global_data.py`（默认最近5年，可指定 `--start/--end`）。

## 券商通道（配合 brokerage 网关）

港美股的交易通道由 `src/quant_demo/brokerage/futu_gateway.py` 提供（富途 OpenAPI，
支持官方模拟盘），内部代码 `0700.HK/AAPL.US` 由适配器自动翻译为富途格式
`HK.0700/US.AAPL`，接入步骤见 `brokerage/README.md`。

## 使用示例

```python
from datetime import datetime
from quant_demo.data import CsvDataService, momentum_rank

svc = CsvDataService("examples/global_stocks_5y.csv")
bars = svc.get_bars(["0700.HK", "AAPL.US"], datetime(2021, 9, 17), datetime(2026, 9, 15))

# 动量选股：跨市场按60日动量取前3
top3 = momentum_rank(bars, as_of=datetime(2026, 9, 1), lookback=60, top_k=3)
```
